Premium Points Credit (M5)

Credit the on-chain PREMIUM points ledger ([gfgprem, player], buy-only) after a VERIFIED manual payment. Runs gasless on the MagicBlock ER (sponsor signs, user never pays).

How it works: pick a user from the dropdown (email and in brackets their embedded wallet from Dynamic), or search by email or wallet to filter the list. Choose a premium preset or type any amount. Credit reference and operator token are auto-filled with safe random values that will not break the program — only edit them if you must. The relay writes premium_lifetime and premium_spendable together (idempotent by credit ref, so a retry can never double-credit). It never touches the M3 local or M4 global game-points ledgers.
Pick from the dropdown to avoid typing errors. List is from Dynamic (source of truth for email + wallet).
Preset fills the amount, but you can still edit the number directly for any promo.
This is the on-chain idempotency key (u64). The program rejects a reused ref, so a retry can never double-credit. Auto-filled with a safe random integer — only edit if you need a specific payment id.
Operator token = GFG_OPERATOR_TOKEN env on the relay. The program checks the stored admin_authority (sponsor key from id.json) and the relay checks this token before it will credit anyone. Without the correct token the relay returns 401. It is auto-filled from your last successful entry and kept in this browser only — only edit if you rotate the token.
