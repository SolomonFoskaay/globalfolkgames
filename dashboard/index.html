✍️ How to update the changelog

The changelog is stored in Git (public/changelog/changelog.json) and never depends on a database, so it is safe from outages. Updates are made by the AI agent, not typed in here. Just tell the agent:

  • "Approve the roadmap item: <title>" → publishes it to the user-facing page.
  • "New feature: <name>, <what it does>" → agent adds it to the roadmap (admin-only until you approve).
  • "Update the summary of the roadmap item: <title>" → agent rewords the public text.
