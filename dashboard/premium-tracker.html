Premium Tracker (M5)

Staff-only list of every premium subscriber. Dynamic is the source of truth for email and wallet (Supabase is only backup for devnet wipe restore). Scan by wallet or Dynamic email, filter by year/month/status, cancel defective perpetual subs, or run promo giveaways (credit 5,000P + activate — still consumes premium, no shortcut).

How cancel works: admin_cancel_subscription is authority-gated and sets level to 0 and activeUntil to 0 on-chain. If the PDA is delegated, the relay undelegates, writes on base, and re-delegates to AS so ER spends keep working. Use it if a sub shows more than 30 days or never expires. Promo give: the tracker first credits 5,000 premium points (idempotent ref) then immediately activates — the activate still checks 5,000 premium spendable, so insufficient balance fails and the spend is recorded in lifetime/spendable.
